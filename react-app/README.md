# Chlydo Tech - React App

This is the React JavaScript version of the Chlydo Tech application, converted from Next.js with TypeScript.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

3. Build for production:
```bash
npm run build
```

## Features

- React 18 with React Router for navigation
- Tailwind CSS for styling
- Radix UI components
- Three.js for 3D graphics
- Lucide React for icons
